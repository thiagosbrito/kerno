# server scope

Root AGENTS.md applies. Everything here is server-only (`import "server-only"` guards the entry point). Never import this package from a client component; `pnpm test:bundles` must stay clean. Service-role access needs narrow use and equivalent explicit authorization. `src/tenancy` is the single tenant-binding resolver (ADR 0004): derive the store only from `getStoreRouter().route(headers)`, never from a forwarded header, client ID, path or cookie; build shared-cache keys with `tenantCacheKey`; the request path uses the anon key. `src/auth` is the single authorization gate (`authorizeOrgAction`, `permissions.ts`): every tenant-scoped action or route goes through it, reads roles from the current membership, writes with the caller's own client (never the service role) and returns 404 to non-members. See [merchant auth](../../docs/security/merchant-auth.md). See [host routing](../../docs/security/host-routing.md).
